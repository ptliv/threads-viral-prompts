## 4. 10가지 바이럴 상황별 최종 과장 프롬프트

`{상품명}`과 `{소용량 1개 형태}`만 변경하여 ChatGPT에 그대로 입력하세요.

1. **아파트 복도 엘리베이터 앞 천장 적재 (배달 기사 사죄 밈)**: 복도 벽면 따라 대량 박스 천장까지 적재.
2. **현관문 개폐 불가 봉쇄 밈 (탈출 불가)**: 현관문이 10cm밖에 안 열릴 정도로 박스 벽이 가로막음.
3. **원룸 방바닥 및 침대 점령 (생활 공간 실종)**: 침대 빼고 바닥 전체가 박스로 테트리스 채워짐.
4. **팬트리 / 다용도실 수납장 창고화**: 선반에 1cm 틈새 없이 편의점 물류창고처럼 빽빽하게 적재.
5. **거실 소파와 테이블이 박스 요새로 변한 상황**: 거실 한가운데 소파를 둘러싸고 2미터 높이 성벽 요새.
6. **지하 주차장 SUV 트렁크 + 뒷좌석 폭발 적재**: SUV 트렁크 열었더니 뒷좌석까지 박스 쏟아질 듯 가득 참.
7. **냉장고 문 열자마자 폭포수 쟁여두기**: 냉장고 문 열자 다른 음식 없이 제품으로만 꽉 차 쏟아질 듯함.
8. **사무실 / 직장 탕비실 싹쓸이 점령**: 탕비실 싱크대와 바닥 전체에 특정 상품 박스 폭탄.
9. **대형 마트 카트 2개 산더미 싹쓸이**: 쇼핑 카트 2대에 피사의 사탑처럼 박스가 산더미로 실림.
10. **야외 캠핑 / 차박 대량 하적 유머**: 캠핑 텐트 옆에 박스 수십 개로 테이블과 의자, 담벼락을 만듦.
